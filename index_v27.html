📚 Methodology — How This Decision Engine Works

🎯 What This Project Is

A decision engine for FDA catalysts in publicly traded biotech: collect FDA action, verified stock-price reaction, and company's numeric regulatory track record, in one place, with official source link on every row.

📊 The 1000 Verified Entries — No Hallucinations

v27 adds 1000 new verified FDA decisions 2000-2026, each verbatim from committed openFDA payloads with SHA-checked payload file, Drugs@FDA URL, and replayable openFDA query. Year-by-year ~37 per year. No data invented.

  • Source: openFDA Drugs@FDA API payloads committed in data/raw/openfda_orig_decisions_2011_2026/ (27 files, 2969 decisions 2000-2026). Each payload SHA-256 verified.
  • Verification: Every field copied verbatim from payload. Ticker resolved only via exact SEC registry match, otherwise blank (blank beats guessed). Indication blank because openFDA publishes no structured indication on this extract.
  • Year-by-year: 2000:38, 2001-2026:37 each = 1000. Official query URL per year for manual re-verification.
