💊 DrugAnalysis

Publicly traded biotech & pharma companies tracked against FDA decisions, stock-price reactions, and clinical pipeline success rates — all sourced from official, verifiable links.

Core Analysis Table

Company, drug, FDA decision, stock-price reaction, and a pipeline success-rate summary — the single table for a fast overview. Empty price cells mean data has not yet been fetched/verified for that row (never estimated). % T+1 is the move from the pre-decision close to the next trading session's close, which is where several approvals actually moved (e.g. Celcuity +7.0% on the day, then −17.6% the next session).

FDA Approvals Master List

277 verified FDA novel drug approvals (2021–2026), one row per decision, each with two source links for manual review. Coverage of FDA’s official novel-approval tables is now complete for 2021 (50/50), 2024 (50/50), 2025 (46/46) and 2026 (39/39 to date). Where the applicant of record has changed since approval (asset sale, acquisition, or licence-out), both the current holder and the original applicant are shown and the row is flagged.

Complete Response Letters (Rejections)

FDA rejections / regulatory setbacks for publicly traded companies — flagged as irregularities worth tracking, including repeat-CRL cases. C004 (Outlook Therapeutics / Lytenava) is marked RESOLVED: after a third CRL on 2025-12-31 the BLA was resubmitted and approved on 2026-07-24.

Stock Price Snapshots

211 closing-price snapshots around FDA decisions, taken from the Yahoo Finance chart API (/v8/finance/chart/<TICKER>?interval=1d) and stored as raw captures in data/staging/ so every number can be re-checked. Rows with blank prices are delisted/acquired tickers whose history the API no longer serves, or a bar that had not published yet at capture time — never a placeholder guess. One series (Nuvalent, 2026-07-22) was rejected rather than recorded because the API returned a degenerate zero-volume series.

Company Pipeline Scorecards

149 per-company scorecards. 36 are deep-dive pipeline scorecards (which programs are in which phase, which advanced, which were paused or put on clinical hold). The remainder cover every other company in the dataset and count only the FDA decisions verified and tracked in this repository — they are labelled “Verified – FDA decisions only (partial pipeline view)” and report phase progression as 0 rather than estimating it.

About & Methodology

Sources

  • FDA decisions — FDA.gov Novel Drug Approvals pages (2021–2026), the application overview pages on accessdata.fda.gov, the official openFDA Drugs@FDA API (api.fda.gov/drug/drugsfda.json, used to resolve the applicant of record for every application number), the official openFDA CRL transparency API (api.fda.gov/transparency/crl.json), and FDA Drug Trials Snapshots.
  • Stock prices — Yahoo Finance chart API (query1.finance.yahoo.com), captured for a ±6-day window around every decision date and stored verbatim in data/staging/prices_new_2026_09.py.
  • Company / ownership changes — the company’s own press release (for example Scholar Rock’s ISEMBYLD approval release and GSK’s Lynavoy release) plus SEC-filing summaries, always cited with a direct link. This is how ownership changes such as Veppanu → Rigel and Lynavoy → Alfasigma were confirmed.

Verification approach

Every row in the approvals and CRL tables carries a verification_status field. Rows are marked Verified only when the company/ticker/date combination was corroborated by at least one official or primary-source link. Anything ambiguous is flagged in the notes rather than silently resolved. Examples of what is flagged rather than smoothed over:

  • Applicant vs. current holder. FDA lists the current applicant of record, which changes after a licence-out or acquisition. Veppanu (NDA 219835) was approved to Arvinas/Pfizer and then licensed to Rigel eleven days later; Lynavoy (NDA 220295) was approved to GSK and then licensed to Alfasigma, so the FDA record now reads “INTERCEPT”. Both rows state the change.
  • Withdrawn products. Pepaxto (NDA 214383) no longer exists in the FDA application database because it was withdrawn in Oct 2021 after its confirmatory trial failed; its sponsor is marked as not machine-verifiable instead of being guessed. Exkivity and Truseltiq are flagged as voluntarily withdrawn.
  • Data conflicts. FDA records Lynavoy’s approval as 2026-03-17 while GSK announced it on 2026-03-19; both dates are given. Outlook Therapeutics was approved on 2026-07-24 yet fell 24.2% and 15.1% over the next two sessions — the cause is flagged for manual review rather than attributed.
  • Rejected data. One price series (Nuvalent) was discarded because the API returned a degenerate zero-volume series; the cells are blank, not filled in.

Known limitations (as of 2026-09-12)

  • review_pathway (Priority / Standard / Accelerated) is populated for the original 200 rows but is deliberately blank for D201–D277: FDA publishes those designations in its annual New Drug Therapy Approvals reports, which do not exist yet for 2026 and were not re-parsed in this pass. Blank beats guessed.
  • FDA has removed its 2019 and 2020 novel-approval pages, so those years are not covered. 2021–2026 is complete.
  • Pre-2021 approvals that were later delisted (ChemoCentryx, Seagen, Kadmon, AVEO) have no retrievable price history from the chart API; those rows are explicit about it.
  • The 2026-09-11 Scholar Rock daily bar had not been published when it was captured, so that one close_on cell is pending a re-fetch.
  • Scorecards added in this pass count FDA decisions tracked here, not full corporate pipelines — see the Scorecards tab.
